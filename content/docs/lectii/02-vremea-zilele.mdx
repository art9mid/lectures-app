<Callout title="Коротко (выжимка)" type="success">
- **Vremea** = погода (не «время»!). *Cum este vremea?* = Какая погода?
- Сегодня: **Astăzi este** luni. Завтра: **Mâine va fi** marți. Вчера: **Ieri a fost** duminică.
- **este** = есть, **va fi** = будет, **a fost** = был / была / было.
- **Astăzi este ploios**, но **Vremea este ploioasă**: прилагательное меняется, потому что *vremea* женского рода.
- Дни недели пишем **с маленькой буквы**: luni, marți, miercuri…
</Callout>

## 1. Vremea (погода)

<Callout type="warn" title="Ложный друг">
**Vremea** звучит почти как русское «время», но значит **погода**. «Время» по-румынски **timp**.
</Callout>

### Cum este vremea? (Какая погода?)

<Ex ro="Astăzi este ploios." ru="Сегодня дождливо." hl="ploios" note="(астэзь есте плойо́с)" />
<Ex ro="Astăzi este însorit." ru="Сегодня солнечно." hl="însorit" note="(астэзь есте ынсори́т)" />
<Ex ro="Astăzi este senin." ru="Сегодня ясно." hl="senin" note="(астэзь есте сени́н)" />
<Ex ro="Astăzi este cald." ru="Сегодня тепло / жарко." hl="cald" note="(астэзь есте калд)" />
<Ex ro="Astăzi este frig." ru="Сегодня холодно." hl="frig" />

### Astăzi este… или Vremea este…?

Одно и то же можно сказать двумя способами. Разница в окончании прилагательного.

<Compare>
<Side title="Astăzi este…" tone="blue">
Безличная фраза («сегодня дождливо»). Прилагательное в **базовой форме**.

<Ex ro="Astăzi este ploios." ru="Сегодня дождливо." hl="ploios" />
<Ex ro="Astăzi este însorit." ru="Сегодня солнечно." hl="însorit" />
</Side>
<Side title="Vremea este…" tone="amber">
**Vremea** женского рода, поэтому прилагательное получает **-ă** или **-oasă**.

<Ex ro="Vremea este ploioasă." ru="Погода дождливая." hl="ploioasă" />
<Ex ro="Vremea este însorită." ru="Погода солнечная." hl="însorită" />
</Side>
</Compare>

| Astăzi este… | Vremea este… | Rusă |
| --- | --- | --- |
| ploios | ploioas**ă** | дождливо / дождливая |
| însorit | însorit**ă** | солнечно / солнечная |
| senin | senin**ă** | ясно / ясная |
| cald | cald**ă** | тепло / тёплая |
| frig *(существительное)* | rece | холодно / холодная |

<Callout type="idea">
**Frig** = холод (существительное), поэтому *Astăzi este frig*, но *Vremea este **rece***. Слово **rece** одинаковое в мужском и женском роде.
</Callout>

## 2. Zilele săptămânii (дни недели)

| Română | Произношение | Rusă |
| --- | --- | --- |
| <Say>luni</Say> | (лунь) | понедельник |
| <Say>marți</Say> | (марць) | вторник |
| <Say>miercuri</Say> | (мьеркурь) | среда |
| <Say>joi</Say> | (жой) | четверг |
| <Say>vineri</Say> | (винерь) | пятница |
| <Say>sâmbătă</Say> | (сымбэтэ) | суббота |
| <Say>duminică</Say> | (думиникэ) | воскресенье |

<Callout type="idea" title="Как запомнить">
Названия идут от планет, как во французском или итальянском: **luni** = Луна, **marți** = Марс, **miercuri** = Меркурий, **joi** = Юпитер, **vineri** = Венера. **Sâmbătă** похоже на «суббота», **duminică** связано со словом «Господь» (лат. *Dominus*).
</Callout>

## 3. Линия времени

Представь, что сегодня **вторник**. Тогда:

| ← позавчера | вчера | **сегодня** | завтра | послезавтра → |
| --- | --- | --- | --- | --- |
| alaltăieri | ieri | **astăzi** | mâine | poimâine |
| duminică | luni | **marți** | miercuri | joi |
| a fost | a fost | **este** | va fi | va fi |

Глагол меняется вместе со временем:

<Formula hl="a fost">Ieri + a fost + ziua</Formula>
<Formula hl="este">Astăzi + este + ziua</Formula>
<Formula hl="va fi">Mâine + va fi + ziua</Formula>

## 5. Упражнения

### Exercițiul 1 · Переведи

1. Сегодня солнечно.
2. Завтра будет вторник.
3. Вчера была суббота.
4. Послезавтра будет среда.

<Answer>
1. Astăzi este însorit.
2. Mâine va fi marți.
3. Ieri a fost sâmbătă.
4. Poimâine va fi miercuri.
</Answer>

### Exercițiul 2 · Ответь на вопросы

Ответы для дня, когда сегодня вторник. Подставь свой день.

1. Ce zi este astăzi?
2. Ce zi va fi mâine?
3. Ce zi a fost ieri?

<Answer>
1. Astăzi este marți.
2. Mâine va fi miercuri.
3. Ieri a fost luni.
</Answer>

### Exercițiul 3 · Дополни

1. Astăzi este ___ (погода).
2. Mâine va fi ___ (день).
3. Ieri a fost ___ (день).
4. Poimâine va fi ___ (день).

<Answer>
Пример (сегодня вторник): Astăzi este însorit. · Mâine va fi miercuri. · Ieri a fost luni. · Poimâine va fi joi.
</Answer>

### Exercițiul 4 · Составь предложения

1. Astăzi …
2. Mâine …
3. Ieri …

<Answer>
Примеры:
1. Astăzi este frig.
2. Mâine va fi vineri.
3. Ieri a fost ploios.
</Answer>
