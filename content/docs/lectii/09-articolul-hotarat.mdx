title: "Lecția 9 · Articolul hotărât"
description: Определённый артикль. Как сказать «книга» и «эта (та самая) книга», и почему в румынском он стоит в конце слова.
---

<Callout title="Коротко (выжимка)" type="success">
- **un / o** = какой-то, любой (неопределённый артикль). Стоит **перед** словом: *o carte* = какая-то книга.
- **-ul, -le, -a, -ua** = та самая, конкретная (определённый артикль). Приклеивается **к концу** слова: *cartea* = (эта) книга.
- Мужской и средний род: **-ul** (*băiatul*), на **-e** → **-le** (*fratele*), на **-u** → **-l** (*lucrul*).
- Женский род: **-ă → -a** (*casa*), **-e → -ea** (*cartea*), ударные **-ea / -i → -ua** (*cafeaua, ziua*).
- Множественное: мужской **-i → -ii** (*băieții*), остальные **+le** (*casele, trenurile*).
- После предлогов (кроме **cu**) артикль обычно не нужен: *pe masă, la școală*. Но: *cu autobuzul*.
</Callout>

## Зачем это нужно

В русском нет артиклей, поэтому мы их пропускаем. В румынском без артикля фраза звучит неправильно. Сравни:

<Compare>
<Side title="un băiat" tone="blue">
какой-то мальчик, впервые упоминаем

<Ex ro="Văd un băiat." ru="Я вижу (какого-то) мальчика." hl="un băiat" />
</Side>
<Side title="băiatul" tone="green">
тот самый мальчик, уже знаем, о ком речь

<Ex ro="Băiatul este student." ru="(Этот) мальчик студент." hl="Băiatul" />
</Side>
</Compare>

<Compare>
<Side title="o carte" tone="blue">
<Ex ro="Am o carte." ru="У меня есть книга." hl="o carte" />
</Side>
<Side title="cartea" tone="green">
<Ex ro="Cartea este pe masă." ru="Книга (та самая) на столе." hl="Cartea" />
</Side>
</Compare>

<Callout type="idea">
Русскоговорящие чаще всего ошибаются в начале предложения. «Книга на столе» по-румынски будет **Cartea** este pe masă, а не ~~Carte este pe masă~~. Если предмет конкретный и уже понятный, ставь артикль.
</Callout>

## Мужской и средний род

<Formula hl="-ul">слово + -ul</Formula>

| Окончание слова | Артикль | Пример |
| --- | --- | --- |
| согласная | **-ul** | un băiat → <Say>băiatul</Say> |
| согласная | **-ul** | un student → <Say>studentul</Say> |
| согласная | **-ul** | un profesor → <Say>profesorul</Say> |
| согласная | **-ul** | un telefon → <Say>telefonul</Say> |
| согласная | **-ul** | un autobuz → <Say>autobuzul</Say> |
| согласная | **-ul** | un caiet → <Say>caietul</Say> |
| согласная | **-ul** | un prieten → <Say>prietenul</Say> |
| -u | **-l** | un lucru → <Say>lucrul</Say> |
| -u | **-l** | un stilou → <Say>stiloul</Say> |
| -e | **-le** | un frate → <Say>fratele</Say> |
| -e | **-le** | un câine → <Say>câinele</Say> |
| -e | **-le** | un munte → <Say>muntele</Say> |
| -ă (мужской) | **-l** | un tată → <Say>tatăl</Say> |

## Женский род

<Formula hl="-a">слово на -ă + -a</Formula>

| Окончание слова | Артикль | Пример |
| --- | --- | --- |
| -ă | **-ă → -a** | o casă → <Say>casa</Say> |
| -ă | **-ă → -a** | o mașină → <Say>mașina</Say> |
| -ă | **-ă → -a** | o școală → <Say>școala</Say> |
| -ă | **-ă → -a** | o soră → <Say>sora</Say> |
| -ă | **-ă → -a** | o pisică → <Say>pisica</Say> |
| -e | **-e → -ea** | o carte → <Say>cartea</Say> |
| -e | **-e → -ea** | o universitate → <Say>universitatea</Say> |
| -e | **-e → -ea** | o floare → <Say>floarea</Say> |
| -ie | **-ie → -ia** | o lecție → <Say>lecția</Say> |
| -ie | **-ie → -ia** | o familie → <Say>familia</Say> |
| -ie | **-ie → -ia** | o stație → <Say>stația</Say> |
| ударное -ea | **+ -ua** | o cafea → <Say>cafeaua</Say> |
| ударное -i | **+ -ua** | o zi → <Say>ziua</Say> |

<Ex ro="Cartea este interesantă." ru="Книга интересная." hl="Cartea" />
<Ex ro="Lecția începe la ora zece." ru="Урок начинается в десять." hl="Lecția" />
<Ex ro="Cafeaua este caldă." ru="Кофе горячий." hl="Cafeaua" />

<Ex ro="prieteni → prietenii" ru="друзья → (эти) друзья" hl="prietenii" />

## Артикль и предлоги

После предлогов **pe, în, la, sub, din, de** существительное без уточнений обычно идёт **без** артикля:

<Ex ro="Cartea este pe masă." ru="Книга на столе." hl="pe masă" />
<Ex ro="Eu sunt la școală." ru="Я в школе." hl="la școală" />
<Ex ro="Copiii sunt în casă." ru="Дети в доме." hl="în casă" />

Если у слова есть уточнение (чей, какой), артикль возвращается:

<Ex ro="Cartea este pe masa mea." ru="Книга на моём столе." hl="masa mea" />
<Ex ro="Locuiesc în casa mare." ru="Я живу в большом доме." hl="casa mare" />

<Callout type="warn" title="Исключение: cu">
После **cu** («с, на чём») артикль нужен: *Merg **cu autobuzul***. *Vin **cu mașina***. *Plec **cu trenul***.
</Callout>

## Упражнения

### 1. Поставь определённый артикль

1. un student →
2. o casă →
3. un frate →
4. o carte →
5. un lucru →
6. o lecție →
7. o cafea →
8. un telefon →

<Answer>studentul · casa · fratele · cartea · lucrul · lecția · cafeaua · telefonul</Answer>

### 2. Множественное число с артиклем

1. băieți →
2. case →
3. copii →
4. trenuri →
5. cărți →

<Answer>băieții · casele · copiii · trenurile · cărțile</Answer>

### 3. Нужен артикль или нет?

1. ___ (carte) este pe masă.
2. Eu merg la ___ (școală).
3. Noi mergem cu ___ (autobuz).
4. ___ (câine) doarme.
5. Ea locuiește în ___ (casă) mare.

<Answer>
1. **Cartea** este pe masă.
2. Eu merg la **școală** (после la без артикля).
3. Noi mergem cu **autobuzul** (после cu артикль нужен).
4. **Câinele** doarme.
5. Ea locuiește în **casa** mare (есть уточнение «mare»).
</Answer>

### 4. Переведи

1. Студент дома.
2. Машина новая.
3. Дети спят.
4. Я еду на поезде.

<Answer>
1. Studentul este acasă.
2. Mașina este nouă.
3. Copiii dorm.
4. Merg cu trenul.
</Answer>
