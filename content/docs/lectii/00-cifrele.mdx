<Callout title="Коротко (выжимка)" type="success">
- **1–10** учим наизусть: unu, doi, trei, patru, cinci, șase, șapte, opt, nouă, zece.
- **11–19**: цифра + **spre** + zece. Особые формы: **unsprezece** (11), **paisprezece** (14), **șaisprezece** (16).
- **20–90**: цифра + **zeci**. *douăzeci, treizeci, șaizeci.*
- **21–99**: десятки + **și** + единицы. *douăzeci **și** unu.*
- **100, 1000**: o sută, o mie. Дальше: două **sute**, două **mii**, două **milioane**.
- После 20 и больше перед словом ставим **de**: *douăzeci **de** mii, o sută **de** mii.*
</Callout>

## Конструктор чисел

Любое большое число собирается по кусочкам слева направо. Разбери 7.845.921:

<Steps>
<Step>
**Миллионы: 7** → *șapte milioane*
</Step>
<Step>
**Тысячи: 845** → *opt sute patruzeci și cinci* + **de mii** (845 кончается на 45, это больше 20, значит нужно «de»)
</Step>
<Step>
**Остаток: 921** → *nouă sute douăzeci și unu*
</Step>
<Step>
**Склеиваем:** *șapte milioane opt sute patruzeci și cinci de mii nouă sute douăzeci și unu*
</Step>
</Steps>

Ещё несколько разборов:

| Число | Миллионы | Тысячи | Остаток | Вместе |
| --- | --- | --- | --- | --- |
| 1.250 | | o mie | două sute cincizeci | o mie două sute cincizeci |
| 12.300 | | douăsprezece mii | trei sute | douăsprezece mii trei sute |
| 25.000 | | douăzeci și cinci de mii | | douăzeci și cinci de mii |
| 105.000 | | o sută cinci mii | | o sută cinci mii |
| 340.500 | | trei sute patruzeci de mii | cinci sute | trei sute patruzeci de mii cinci sute |
| 2.005.000 | două milioane | cinci mii | | două milioane cinci mii |

<Callout type="warn" title="Правило «de»">
Если последние две цифры числа **00** или **от 20 до 99**, перед существительным ставим **de**:

- 20 **de** mii, 25 **de** mii, 100 **de** mii, 200 **de** mii
- 20 **de** lei, 45 **de** ani, 100 **de** euro

Если последние две цифры от 1 до 19, **de** не нужно:

- 2 mii, 12 mii, 105 mii
- 5 lei, 19 ani, 112 euro

Это правило работает с любым словом: *Am treizeci **de** ani* (мне 30 лет), но *Am nouăsprezece ani* (мне 19 лет).
</Callout>

<Callout type="idea" title="Женские формы перед sute, mii, milioane">
**Sută** и **mie** женского рода, **milioane** во множественном числе ведёт себя так же. Поэтому «два» превращается в **două**, «двенадцать» в **douăsprezece**:

- **două** sute, **două** mii, **două** milioane
- **douăsprezece** mii, douăzeci și **două** de mii

А при простом счёте: doi, doisprezece, douăzeci și doi.
</Callout>

## Общая схема

| Диапазон | Правило |
| --- | --- |
| 1–10 | запоминаем |
| 11–19 | cifra + **spre** + zece |
| 20–90 | cifra + **zeci** |
| 21–99 | zeci + **și** + unități |
| 100–900 | număr + **sută / sute** |
| 1.000–999.999 | număr + **mie / mii** |
| 100.000–999.000 | număr + **sută / sute de mii** |
| 1.000.000+ | număr + **milion / milioane** |
