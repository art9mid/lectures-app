<Callout title="Коротко (выжимка)" type="success">
- **Voi / dumneavoastră** (вы): форма как в настоящем времени. *Citiți! Veniți! Ascultați!*
- **Tu** (ты): чаще всего форма 3-го лица, *el citește → Citește!* Несколько глаголов нужно выучить: **Vino! Fă! Du-te! Ia! Zi!**
- **Отрицание для tu**: **nu + инфинитив без «a»**. *Nu fuma! Nu veni!*
- **Отрицание для voi**: nu + обычная форма. *Nu fumați!*
- На экзамене все задания написаны в imperativ: *Citiți textul. Alegeți varianta corectă.*
</Callout>

## Вы: voi / dumneavoastră

Самая простая форма. Берёшь «voi» из настоящего времени и убираешь местоимение.

| Infinitiv | voi (prezent) | Imperativ |
| --- | --- | --- |
| a veni | voi veniți | **Veniți!** |
| a citi | voi citiți | **Citiți!** |
| a asculta | voi ascultați | **Ascultați!** |
| a scrie | voi scrieți | **Scrieți!** |
| a face | voi faceți | **Faceți!** |
| a lua | voi luați | **Luați!** |
| a intra | voi intrați | **Intrați!** |

<Ex ro="Intrați, vă rog!" ru="Входите, пожалуйста!" hl="Intrați" />
<Ex ro="Luați loc!" ru="Садитесь! (займите место)" hl="Luați" />

<Callout type="idea">
К незнакомым людям, врачу, чиновнику обращаются на «вы»: **dumneavoastră**. Форма та же: *Spuneți, vă rog…*
</Callout>

## Ты: tu

Чаще всего форма совпадает с «el / ea» в настоящем времени.

| Infinitiv | el / ea (prezent) | Imperativ (tu) |
| --- | --- | --- |
| a citi | el citește | **Citește!** |
| a asculta | el ascultă | **Ascultă!** |
| a lucra | el lucrează | **Lucrează!** |
| a vorbi | el vorbește | **Vorbește!** |
| a intra | el intră | **Intră!** |
| a aștepta | el așteaptă | **Așteaptă!** |

У глаголов на **-e** (a merge, a scrie, a spune, a deschide) форма совпадает с «tu»:

| Infinitiv | Imperativ (tu) |
| --- | --- |
| a merge | **Mergi!** |
| a scrie | **Scrie!** |
| a spune | **Spune!** |
| a deschide | **Deschide!** |
| a închide | **Închide!** |

## Отрицание

<Compare>
<Side title="tu: nu + инфинитив" tone="red">
**Nu fuma!** Не кури!

**Nu veni!** Не приходи!

**Nu vorbi!** Не говори!

**Nu face asta!** Не делай этого!
</Side>
<Side title="voi: nu + форма на -ți" tone="blue">
**Nu fumați!** Не курите!

**Nu veniți!** Не приходите!

**Nu vorbiți!** Не разговаривайте!

**Nu faceți asta!** Не делайте этого!
</Side>
</Compare>

<Callout type="warn">
Для «tu» отрицание строится от инфинитива, не от утвердительной формы. *Vino!*, но *Nu **veni**!* *Fă!*, но *Nu **face**!*
</Callout>

## Возвратные глаголы

Местоимение ставится после глагола через дефис. В отрицании оно идёт перед глаголом.

| | tu | voi |
| --- | --- | --- |
| a se așeza (садиться) | **Așază-te!** | **Așezați-vă!** |
| a se grăbi (торопиться) | **Grăbește-te!** | **Grăbiți-vă!** |
| a se trezi (просыпаться) | **Trezește-te!** | **Treziți-vă!** |
| отрицание | **Nu te grăbi!** | **Nu vă grăbiți!** |

## Упражнения

### 1. Сделай форму для tu и voi

1. a asculta
2. a scrie
3. a veni
4. a face
5. a citi

<Answer>
1. Ascultă! / Ascultați!
2. Scrie! / Scrieți!
3. Vino! / Veniți!
4. Fă! / Faceți!
5. Citește! / Citiți!
</Answer>

### 2. Поставь в отрицание

1. Fumează!
2. Vino!
3. Vorbiți!
4. Grăbește-te!
5. Fă asta!

<Answer>
1. Nu fuma!
2. Nu veni!
3. Nu vorbiți!
4. Nu te grăbi!
5. Nu face asta!
</Answer>

3. Împingeți
4. Nu fumați!

<Answer>
1. На себя · 2. Выход · 3. От себя · 4. Не курить!
</Answer>
