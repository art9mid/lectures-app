### Три буквы A

- **A** = А (как русское А)
- **Ă (ă)** = Э (среднее между А и Э)
- **Â (â)** = Ы (как русское Ы)

### Две буквы I

- **I** = И (как русское И)
- **Î (î)** = Ы (как русское Ы)

> **!** Главные исключения и особенности:
> - Â (â) и Î (î) звучат одинаково -- оба как Ы!
> - S и Ș (ș) -- это разные буквы
> - T и Ț (ț) -- это разные буквы
> - X = кс (text, taxi) или гз (examen, exemplu)

## ОСОБЫЕ СОЧЕТАНИЯ БУКВ

### CE, CI = ЧЕ, ЧИ

Перед E и I буква C читается как Ч.

| Română | Перевод |
|--------|---------|
| Ce? | Что? |
| Cine? | Кто? |
| cerneală | чернила |
| cerc | круг |
| accent | акцент |
| concert | концерт |
| cilindru | цилиндр |
| aici | здесь |
| arici | ёжик |
| cinci | пять (5) |

### CHE, CHI = КЕ, КИ

Добавляем H, чтобы C читалась как К перед E и I.

| Română | Перевод |
|--------|---------|
| ureche / urechi | ухо / уши |
| cheie | ключ |
| chemare | вызов |
| ochi | глаз / глаза |
| ochelari | очки |
| chibrit | спичка |
| chimie | химия |
| China | Китай |

### GE, GI = ДЖЕ, ДЖИ

Перед E и I буква G читается как ДЖ.

| Română | Перевод |
|--------|---------|
| ger | мороз |
| girafă | жираф |
| algebra | алгебра |
| geometrie | геометрия |
| Germania | Германия |
| gigant | гигант |
| argint | серебро |

### GHE, GHI = ГЕ, ГИ

Добавляем H, чтобы G читалась как Г перед E и I.

| Română | Перевод |
|--------|---------|
| Gheorghe | Георге (имя) |
| gheață | лёд |
| înghețată | мороженое |
| ghid | гид |
| ghilimele „ " | кавычки |
| ghicitoare | загадка |
| triunghi | треугольник |
| ghiozdan | рюкзак |
| ghiocel | подснежник |
| ghem | клубок |

> **!** ПРАВИЛО CE/CI и GE/GI:
> - C + E/I = Ч (ce = че, ci = чи) --> добавляем H: CHE/CHI = КЕ/КИ
> - G + E/I = ДЖ (ge = дже, gi = джи) --> добавляем H: GHE/GHI = ГЕ/ГИ
> - Буква H в сочетаниях CH и GH не произносится!

## ГЛАГОЛЫ (VERBELE)

### A FI = БЫТЬ

| Лицо | A fi | Перевод |
|------|------|---------|
| Eu | sunt | Я есть |
| Tu | ești | Ты есть |
| El/Ea | este (e, -i) | Он/она есть |
| Noi | suntem | Мы есть |
| Voi | sunteți | Вы есть |
| Ei/Ele | sunt | Они есть |

> **i** Краткие формы: este --> e --> -i (Mama-i acasă = Мама дома)
> **i** Отрицание: nu sunt --> nu-s (Ei nu-s aici = Их нет здесь)

### A AVEA = ИМЕТЬ

| Лицо | A avea | Отрицание |
|------|--------|-----------|
| Eu | am | nu am / n-am |
| Tu | ai | nu ai / n-ai |
| El/Ea | are | nu are / n-are |
| Noi | avem | nu avem / n-avem |
| Voi | aveți | nu aveți / n-aveți |
| Ei/Ele | au | nu au / n-au |

Примеры с "Eu am...":

| Română | Перевод |
|--------|---------|
| Eu am părinți. | У меня есть родители. |
| Eu am copii. | У меня есть дети. |
| Eu am prieteni. | У меня есть друзья. |
| Eu am sănătate. | У меня есть здоровье. |
| Eu am bucurii. | У меня есть радости. |
| Eu am bani. | У меня есть деньги. |
| Eu am casă. | У меня есть дом. |
| Eu am mașină. | У меня есть машина. |
| Eu am totul. | У меня есть всё. |

### A FACE = ДЕЛАТЬ

| Лицо | A face | Перевод |
|------|--------|---------|
| Eu | fac | Я делаю |
| Tu | faci | Ты делаешь |
| El/Ea | face | Он/она делает |
| Noi | facem | Мы делаем |
| Voi | faceți | Вы делаете |
| Ei/Ele | fac | Они делают |

> **i** Ce faci? = Как дела? Mulțumesc, fac bine. = Спасибо, хорошо.
